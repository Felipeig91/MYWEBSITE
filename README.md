# MYWEBSITE

Personal portfolio website for Felipe Pinuer.

## Local preview

Open `index.html` directly in a browser or use any static web server from the project root.

## GitHub Pages

The site is deployed automatically from the `main` branch through the workflow in
`.github/workflows/pages.yml`. In the repository settings, set **Pages > Build and
deployment > Source** to **GitHub Actions**.

The site uses only static files:

- `index.html`
- `styles.css`
- `script.js`
- `assets/felipe-pinuer.png`
